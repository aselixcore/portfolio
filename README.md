# Alexis Zapia — Portfolio

Portfolio personal en forma de editor de código navegable. Cada sección de mi CV
(experiencia, proyectos, stack, educación, certificaciones, contacto) es un
"archivo" abrible desde un explorador lateral, con resaltado de sintaxis según
su extensión y una terminal funcional para navegar escribiendo comandos.

Antes de entrar al editor, una intro simula el arranque de una Commodore 64
cargando un cassette — con sonido generado en vivo con Web Audio, sin archivos
de audio externos.

**Sitio en vivo:** https://aselixcore.github.io

## Stack

- HTML, CSS y JavaScript vanilla — sin frameworks, sin build tools, sin
  dependencias externas (más allá de una fuente de Google Fonts).
- Todo vive en un único `index.html`, pensado para desplegarse tal cual en
  GitHub Pages.

## Correr en local

No requiere instalación. Cloná el repo y abrí `index.html` en el navegador:

```bash
git clone https://github.com/aselixcore/aselixcore.github.io.git
cd aselixcore.github.io
open index.html   # o doble clic en el archivo
```
